# シギッチクイズ

小学生向けの自然・農業・環境クイズ。静的 HTML / CSS / JavaScript のため、GitHub Pagesで動作します。

## 起動と確認

`npm install` → `npm run serve` → http://localhost:4173

別ターミナルで `npm test`。Google Chromeを使用して全問の進行、採点、解説、再挑戦、画面幅、確認ページを検証します。

## 問題データ

`questions.json` に全41問を記録。`active: true` の26問が出題対象です。15問は正解・資料・実物画像などの確認待ちとして保留しています。先生向け画面 `teacher.html` に修正点・保留理由・確認資料を表示します。

原稿は `source/original.txt` にそのまま保存。再整理の手順は `scripts/prepare.py` にあります。問題データを手作業で変更した後は、このスクリプトで上書きしないでください。

正答率に100をかけて四捨五入。複数回答は正解の組み合わせと完全一致で1問正解です。10問モードは重複なしでランダム、全問モードは全出題対象をランダムに出題。再挑戦時はその問題セットを分母として採点し直します。

## イラスト

ビルトイン imagegen で原稿41問それぞれとタイトル背景を生成。配信用WebPは `assets/`。生成プロンプトは `source/image-prompts.json`。元のPNGはローカルに残し、配信には軽量化した画像を使用します。

個人情報の入力・回答の永続保存・アクセス解析はありません。音は初期状態でオフ、オンにすると正誤の効果音が鳴ります。
